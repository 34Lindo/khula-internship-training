### 1. What is a binary tree?

A binary tree is a data structure where each node can have at most two children: a left child and a right child.

### 2. What is a leaf?

A leaf is a node that has no left or right children.


# Day 2 Assessment — Pascal's Triangle

### 1. What is Pascal's Triangle?

Pascal's Triangle is a pattern of numbers where every row starts and ends with `1`, and each middle number is calculated by adding the two numbers directly above it.

### 2. What does a nested list mean?

A nested list is a list containing other lists.

Example:

```python
[
    [1],
    [1, 1],
    [1, 2, 1]
]
```
